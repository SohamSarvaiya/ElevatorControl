Elevator Control Demo App 🚀


This is a demo Elevator Control application built using the latest Jetpack Compose and Clean Architecture principles. The app is designed to simulate a lift control system with the following features:


Key Features
🚀 20 Floor Setup: Users can select a floor (e.g., Floor 5), and the elevator status updates in real-time.
🛠 Up & Down Arrows: Allows users to interact with lift controls for floor navigation.
📊 Real-Time Updates:
Displays the current floor in real-time using StateFlow.
Shows "Doors Open" and "Doors Closed" status messages dynamically.


🧪 Testing:
Includes Unit Tests using JUnit4.
Android Instrumentation Tests with Espresso for UI testing.


💡 Modern Architecture:
Built with Clean Architecture, ViewModels, and Coroutines.
Implements Repository Pattern for clean and maintainable code.
Tech Stack
Kotlin
Jetpack Compose
StateFlow
Coroutines
ViewModel
JUnit4 & Espresso (for testing)

This app is purely for demonstration purposes and does not control a real-life elevator system. It serves as a foundation to understand state management, UI interactions, and testing in modern Android development.
